# 서울 자치구 경계 데이터

- 파일: `seoul-districts.geojson`
- 원본: [southkorea/seoul-maps](https://github.com/southkorea/seoul-maps)의 `kostat/2013/json/seoul_municipalities_geo_simple.json`
- 표시된 원자료: KOSTAT SGIS, JUSO
- 원본 기준 연도: 2013
- 라이선스: Apache License 2.0
- 사용 목적: 서울 25개 자치구의 선택형 개요 지도
- 적용일: 2026-10-20

이 경계는 여행 지역 선택을 위한 단순화된 시각 자료다. 토지 경계, 행정 증명 또는 정밀 측량 용도로 사용하지 않는다. 최신 서울시 경계와의 정기 재검증이 필요하다.

## 한강 수계

- 파일: `hangang.geojson`
- 원본: [OpenStreetMap way 378066781](https://www.openstreetmap.org/way/378066781), `waterway=river`, `name=한강`
- 좌표계: WGS84 경도·위도. 자치구 경계와 동일한 화면 투영 함수를 사용한다.
- 라이선스: Open Data Commons Open Database License 1.0
- 표기: © OpenStreetMap contributors
- 추출일: 2026-10-20

지도에서는 실제 수계 중심선 좌표에 화면 축척에 맞는 제한된 폭을 적용한다. 이는 관광 탐색용 표현이며 수면 경계나 정밀 측량 자료가 아니다.
